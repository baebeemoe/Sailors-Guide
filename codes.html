How to Redeem a Code

Follow these four steps in Star Sailors, then paste one of the active codes from the table below.

01
☰

Open the Menu

From the main screen, click the Menu button in the upper-right corner.

02
👤

Open Account

From the menu panel, select Account.

03
✦

Select Redeem

Under Account Info, find the CS Code section and click Redeem.

04
⌨

Paste the Code

Paste the copied code into Coupon Code, then click Use Coupon.
