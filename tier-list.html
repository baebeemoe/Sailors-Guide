Tier List by DoeL, CEO of S.E.G.S

Character ranking: Patch 1.2 / Collab Update · Source update: Aug. 27, 2026.

DoeL's assessment is based on character kits and overall PvE performance on the current patch, without Signature Memory being included in the character assessment.

SS — Exceptional characters that fit almost any lineup and provide very strong damage or utility.
S / S+ — Essential high-impact characters for important PvE content.
A — Strong overall performance with some limitations or more specific usage.
B — Good fillers when stronger options are unavailable.
C — Useful for specific functions but less relevant to the current meta.
D — Currently not recommended.

Memory ranking is DoeL's PvE tier list. S = highly versatile and in demand; A = very strong with some conditions; B = usable; C = niche/questionable usage; D = primarily Memory Skill level-up fodder.
